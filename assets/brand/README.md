# Kokon brand assets

Generated by `scripts/brand/kokon_brand.py` from one geometric definition of the mark
(variant C, "cocoon + wings": a capsule stem, the cocoon, and two wings, the upper one larger,
emerging from it). Edit the script, not the files, and rebuild:

```
python scripts/brand/kokon_brand.py build c      # needs pillow numpy fonttools brotli skia-pathops
python scripts/brand/kokon_brand.py preview      # variant comparison sheet (explorations/)
```

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0D0D0D` | mark, wordmark, dark tiles (same as the app's text colour) |
| Paper | `#F7F6F2` | app icon tile, mark on dark backgrounds |

The app UI itself is monochrome (see `src/styles.css`).

## Files

| Folder | What | Where to use it |
| --- | --- | --- |
| `icon/kokon-icon*` | light squircle tile with the black mark | desktop app (installed into `src-tauri/icons`) |
| `icon/kokon-icon-inverse*` | black tile, light mark | website, social avatars, anywhere but the desktop app |
| `icon/macos/` | macOS icon on Apple's template grid (824 px squircle in 1024, 100 px margin, soft shadow), PNGs + `kokon.icns` | installed into `src-tauri/icons/macos` (used by `tauri.macos.conf.json`, also the Dock icon in dev) |
| `icon/kokon-app.ico` | Windows icon, 16–256 px each drawn directly | copied to `src-tauri/icons/icon.ico` (app, installer, uninstaller) |
| `mark/` | the mark alone on transparent, black and light | documents, slides, merch |
| `logo/` | mark + "Kokon" (Inter SemiBold, outlined) | README header, website header; `-white` on dark backgrounds |
| `web/` | favicon.ico/.svg, apple-touch-icon, 192/512 icons (inverse tile) | website |
| `social/` | 1280×640 preview | GitHub social preview, link cards |

## Rules

- Keep clear space around the mark of at least the stem width on every side.
- Do not recolour the parts separately, rotate, stretch or add effects.
- Below 24 px use the icon tile, not the bare mark.

`explorations/` holds the variants considered (A, B, C); C was chosen on 2026-10-08.
