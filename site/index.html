Features

Made for people, not for pipelines.

No nodes, no samplers, no VRAM math. Write what you want; Kokon handles the rest.

Paint an area. Only that area changes.

Brush over a part of the photo, then choose Change, Remove, Replace or Add. The model sees exactly where you painted, and every pixel outside the brush stays as it was.

Zero settings.

Size, memory and upscaling are chosen for your GPU. Pick Fast, Balanced or Quality. That's it.

Every version kept.

Each edit becomes a new version. Compare before and after, undo, or branch from any step.

Private by design.

Your photos and prompts never leave your computer. Turn on private mode and nothing is kept at all: no gallery, no files, no history.

FAQ

Questions.

Is it really free?

Yes. Kokon is open source under the AGPL-3.0 license. No account, no credits, no subscription. It uses your own GPU, so there is nothing to pay for.

Which model does it use?

Qwen-Image 2.1 Turbo, the official 8-step version of Qwen's image model, which leads the open-weights image-editing rankings. It runs through stable-diffusion.cpp, so no Python is needed.

My GPU has 8 GB. Will it work?

Not well today. 12 GB is the smallest size that gives good results with this model. On a Mac, 16 GB of unified memory works but slowly; 32 GB is recommended.

Can I use the images commercially?

The app's code is AGPL-3.0. The model weights have their own licenses: read the Qwen-Image model page before commercial use. The optional upscaler is non-commercial (CC BY-NC-SA 4.0).

Windows says the app is unrecognized. Is it safe?

The beta installer is not code-signed yet, so SmartScreen warns about it. Click "More info" and then "Run anyway". The code is public and every download the app makes is checked against a pinned hash.

Does it work offline?

Yes. After setup has downloaded the models, everything runs offline.
