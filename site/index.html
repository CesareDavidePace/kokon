How it works

Run Qwen-Image 2.1 locally in three steps.

No Python environment, no ComfyUI workflows, no model files to hunt down. Read the full guide.

1

Download the installer

A 35 MB native app for Windows 10/11 or macOS on Apple Silicon. It installs for your user, no admin rights needed.

2

Let it set up the model

Kokon detects your GPU (NVIDIA, AMD, Intel or Apple Silicon), picks the right preset and downloads Qwen-Image 2.1 Turbo, with resume and SHA-256 checks.

3

Describe the change

Drop a photo, write what you want and press Enter. Or paint an area first, and only that area changes.

FAQ

Questions.

Is it really free?

Yes. Kokon is open source under the GNU AGPL-3.0 license. No account, no credits, no subscription. It uses your own GPU, so there is nothing to pay for.

How do I run Qwen-Image 2.1 locally without ComfyUI?

Install Kokon and let its setup download the model. Kokon runs Qwen-Image 2.1 through stable-diffusion.cpp, a native engine, so there is no Python, no ComfyUI and no workflow to build. The step-by-step guide is at kokon.app/qwen-image-2-1-local.

Which model does it use?

Qwen-Image 2.1 Turbo, the official 8-step version of Qwen's image model, which both creates and edits images and leads the open-weights image-editing rankings.

Does it work on AMD or Intel GPUs?

Yes, in beta, through the Vulkan engine on Windows with 12 GB of VRAM or more. On NVIDIA it uses CUDA; on Apple Silicon Macs it uses Metal.

My GPU has 8 GB. Will it work?

Not well today. 12 GB is the smallest size that gives good results with this model. On a Mac, 16 GB of unified memory works but slowly; 32 GB is recommended.

Can Claude Code or Cursor generate images with it?

Yes. Kokon ships an MCP server: register it once and any MCP client can create, edit, inpaint, expand and upscale images on your GPU, for free and without an API key.

Is it an alternative to Photoshop Generative Fill?

For many edits, yes: paint an area and describe what should be there, or remove, replace and add objects. It runs offline and costs nothing, but it is an AI editor, not a full layer-based image editor.

Can I use the images commercially?

Not with the default model. The app is open source (AGPL-3.0), but Qwen-Image 2.1 is released under the Qwen Research License: research and evaluation only, no commercial use without a license from the Qwen team. The optional upscaler is also non-commercial (CC BY-NC-SA 4.0).

Windows says the app is unrecognized. Is it safe?

The beta installer is not code-signed yet, so SmartScreen warns about it. Click "More info" and then "Run anyway". The code is public and every download the app makes is checked against a pinned hash.

Does it work offline?

Yes. After setup has downloaded the models, everything runs offline.
